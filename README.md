# 🎮 Tic Tac Toe Game using Kivy (Python)

This project is a classic *Tic Tac Toe (X-O)* game built using the *Python Kivy Framework*. It is designed to work on both desktop and Android platforms.

## 🧠 Features

- 🧑‍🤝‍🧑 Two-player mode (Player X and Player O)
- 🔁 *Reset Game* button to restart the match
- 🎉 Pop-up message when a player wins
- 😶‍🌫 Draw message when there’s no winner
- 🟩 Winning cells are highlighted in green
- 🖤 User-friendly and stylish interface

## 🚀 How to Run

### 🔧 Requirements:

- Python 3.x
- Kivy framework

### 🛠 Install Kivy:

```bash
pip install kivy

▶ Run the Game:

python "tic tac toe kivy.py"
